# 关于2026大数据挑战赛Tushare数据平台免费权限申请的通知

各参赛团队、各位选手：

为更好地支持大家进行模型构建与数据分析，大赛主办方已与 Tushare 数据平台达成合作。Tushare 将为参赛队伍免费开通专属数据权限（初始即赠送 10000 积分权限，可调用 Tushare 平台 95% 以上的接口）。

现将权限申请、线上填表及审核流程通知如下，请有需要的队伍按要求申请：

## 一、Tushare 账号注册与配置

请以队伍为单位进行申请，具体流程如下：

1. **队长注册**：由队长登录 Tushare 官网（tushare.pro）注册账号。
2. **设置签名**：登录后，进入"个人中心"——"账号与TOKEN"，在签名处准确填写：中国高校计算机大赛——大数据挑战赛。
3. **共享 Token**：权限开通后，队长可在"个人中心"——"账号与TOKEN"获取 Token。同队成员可共用此 Token 调用数据，无需重复申请。
4. **权限期限**：本次赛事专属权限有效期至 2026年8月31日。

## 二、线上表单填写与审核说明

1. 完成账号注册后，请队长填写线上申请表（https://365.kdocs.cn/l/cdXeJFxIKlpr）并提供 Tushare 账号 ID 以供审核开通。
2. 精准填写：队长在提交信息前请务必认真核查，确保账号 ID 等关键信息准确无误，字符之间切勿包含空格或其他多余符号。
3. 定期审核：主办方将于每周三统一对收集到的申请信息进行集中审核。
4. 权限下发：审核通过后，Tushare 工作人员将在 2 个工作日内为选手开通对应权限，请留意账号状态。

祝各队伍在比赛中取得优异成绩！
