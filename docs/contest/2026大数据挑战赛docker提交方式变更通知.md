# 2026大数据挑战赛docker提交方式变更通知

各参赛团队、各位选手：

近日，在线上赛A阶段首次模型代码提交过程中，组委会接到反馈，部分队伍上传docker所使用的网盘链接出现失效情况。为了给大家提供更稳定、便捷的提交体验，经组委会商议，决定对docker提交流程进行优化，具体调整如下：

## 1. 实行"先结果，后代码"的分步提交

- 不再需要队伍同时提交 result.csv 与 docker 文件。
- 后续所有队伍统一**先行提交 result.csv 结果文件**。平台将根据得分进行排名，**排名靠前的队伍进入 docker 提交环节**（线上赛A阶段每次选取前 20 名，线上赛B阶段选取各奖项名额上限的 120%）。

## 2. 开放平台专属上传入口

- 需要提交 docker 的入围队伍不再使用网盘提交，竞赛平台届时将开放专属上传入口，选手直接在系统内上传 docker 即可。
- 上传入口开放时间为线上赛每次排行榜公布日的次日。
- A 阶段首次成绩排行榜发布及 docker 上传
  1. 成绩排行榜发布时间：2026年5月5日
  2. 前20队伍 docker 上传时间：2026年5月6日 10:30-23:59
  3. 前20队伍 docker 上传入口：https://www.heywhale.com/org/r9xi8/competition/area/69c0dfa34f302f8f0122e1bb/submit
  4. 其余阶段成绩排行榜发布及 docker 上传时间另行通知。

## 3. 重申"完全一致"的代码复现要求

- 代码审核环节将严格执行可复现性审查。选手提交的模型代码运行生成的结果必须与此前在平台提交的 result.csv 结果完全一致。对于复现结果和提交结果不一致或代码不可复现的队伍，组委会将剔除其成绩并有权取消其获奖资格。

## 【特别说明】

本次调整仅针对 docker 提交方式，大赛其余赛程安排、数据规范及评审标准均保持不变。感谢各位选手的理解与配合！因网盘突发状况给大家带来的不便，组委会深表歉意。预祝各位选手在后续的比赛中进展顺利，取得优异成绩！
